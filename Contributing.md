# Contributing to Knowledge Quest

This project is not about code. It’s about knowledge quality.

### Before Submitting an Observation, Ask:

1. **Did this actually happen?**
   Log events, not theories.
2. **Are you separating observation from interpretation?**
   Facts ≠ Inferences ≠ Opinions
3. **Can someone else verify the event?**
   Date, context, system involved. Make it reproducible.
4. **Does this add signal rather than noise?**
   One clear friction > 10 vague complaints
5. **Would this still matter in five years?**
   We write about mechanisms, not products.

### How to Contribute
1. Use `Observation Vault/Intake_Template.md` or open an [Observation Issue]
2. Tag correctly: `observation`, `field-note`, `research`, etc.
3. Move through the Flywheel: Observe → Research → Pattern → Handbook

*We build memory, not content.*
