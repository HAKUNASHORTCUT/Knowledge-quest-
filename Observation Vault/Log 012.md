# Log_012: Gate 1 Infrastructure - Security Creates Friction

**Source**: People Daily, Safaricom Clarification

### What happened?
Safaricom clarified repeated logouts on My OneApp over Wi-Fi for customers abroad.
Reason: "Built-in security verification process".

### Why did it matter?
Shows Gate 1 evolution: It's not just "do you have internet". 
It's "can you stay connected reliably without being flagged".
Infrastructure now includes security systems that exclude diaspora users.
New coordinate: Access = Device + Internet + Stable Verification.
